# scratchpad — raw brain-dumps

Shoot random shit here. No structure, no ID, no review. One file per thought, or append to
a dated `YYYY-MM-DD.md` — whatever's fastest. `bin/plan scratch "…"` drops a note here.

When something's worth pursuing, promote it: `bin/plan idea <file>` mints it a **SKY-###**
and moves it to `../ideas/`. Everything downstream of here carries that ID for life.
