# 🧠 scratchpad — raw brain-dumps

**`scratchpad`** ▸ ideas ▸ backlog ▸ projects ▸ archive

**The inbox. Zero friction, zero commitment.** Shoot random shit here — no structure, no ID,
no review, nothing to justify. One file per thought, or append to a dated `YYYY-MM-DD.md`,
whatever's fastest. `bin/plan scratch "…"` drops a note without you even leaving the terminal.

Half of what lands here will never leave, and that's the point — this is where ideas are cheap.

**→ Out:** when a thought is worth pursuing, `bin/plan idea <file>` mints it a **SKY-###** and
graduates it to [`../ideas/`](../ideas/). From that moment it carries that ID **for life**.
