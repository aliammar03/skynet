# services — planned services to add

Catalog of services to bring onto "the Skynet way" (see the `skynet-service-standard` memory
+ `docs/conventions.md`). Each entry is a SKY-### sketch: what the service is, why, image/compose
notes, secrets/DNS/backup needs. When we commit to onboarding one, `bin/plan start SKY-###`
turns it into a project with the real deployment phases.
